# 第三方合婚报告核对流程

用户/使用者提供第三方命理报告时，不要信任任何结论——逐项核对。

## 核对顺序

1. **四柱** — 必须一字不差。任何差异 = 输入数据或真太阳时不同。
2. **大运方向** — 最容易错的地方。
3. **十神** — 四柱一致则十神必然一致。
4. **合婚结论** — 最后核对。

## 大运方向核验：阴阳判定

大运排法规则：

| 性别 | 年干 | 排法 |
|------|------|------|
| 男 | 阳(甲丙戊庚壬) | 顺排 |
| 男 | 阴(乙丁己辛癸) | 逆排 |
| 女 | 阳 | **逆排** |
| 女 | 阴 | 顺排 |

### 示例：1985年乙丑年生 女命

```
乙 = 阴干
女命 + 阴年 → 必须顺排
第三方报告：逆排 ❌（把乙当阳干）
→ 大运序列全错
```

### 快速判定法

逆排从月柱向前数：丙戌 → 乙酉 → 甲申 → 癸未 → 壬午 → 辛巳 → ...
顺排从月柱向后数：丙戌 → 丁亥 → 戊子 → 己丑 → 庚寅 → 辛卯 → ...

第三方报告说「乙酉大运」= 月柱在丙戌且逆排 → 违反女命阴年顺排规则。

## 起运年龄差异

lunar-python 可能给出 0-2 岁起运，第三方给 5-10 岁。这不一定是错误：

- lunar-python：精确按出生日到节气天数/3 计算，第一步可能是短运
- 传统派：可能取整数或从 1 岁/10 岁起算

差异在 1-3 岁内属正常算法差异。差异超过 5 岁 = 排法错误。

## 验证步骤

```python
from lunar_python import Solar

# 以任意出生信息为例（请替换为实际数据）
birth = Solar.fromYmdHms(1985, 11, 3, 14, 20, 0)
lunar = birth.getLunar()
ba = lunar.getEightChar()

# 1. 确认年干阴阳
nian_gan = lunar.getYearGan()
is_yang = nian_gan in '甲丙戊庚壬'
print(f"年干：{nian_gan} → {'阳' if is_yang else '阴'}干")

# 2. 确认排法
yun = ba.getYun(0)  # 0=女
print(f"排法：{'顺排' if yun.isForward() else '逆排'}")

# 3. 列出大运
for d in yun.getDaYun()[:6]:
    print(f"  {d.getGanZhi()} {d.getStartAge()}-{d.getEndAge()}岁")
```
