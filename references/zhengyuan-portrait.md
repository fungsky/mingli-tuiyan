# 正缘画像分析模板

基于干支推配偶/正缘特征。「无法从八字确定」的就说无法确定。

## 核心逻辑

- **男命正财** = 正妻星（日干所克且阴阳异性）→ 癸水克丙火
- **女命正官** = 正夫星（克日干且阴阳异性）→ 戊土克癸水
- **夫妻宫** = 日支

## 分析维度

1. **正财/正官位置**：天干透出 vs 藏干暗藏 → 判断正缘出现的早晚和外显程度
2. **藏干位置**：年柱=早年/祖辈，月柱=青年/事业期，日柱=中年/自身，时柱=晚/子女 → 判断出现的阶段
3. **五行属性**：正财/正官的五行 → 配偶气质（火=热情外向，土=稳重可靠等）
4. **夫妻宫**：日支的五行、生肖、藏干 → 配偶外貌/性格
5. **夫妻宫与日主关系**：生/克/同 → 配偶对日主是滋养型还是约束型
6. **偏缘警示**：女命日支藏七杀（己土）=容易被强势/控制欲强的偏缘干扰
7. **十神格局**：劫财在年=早婚不顺，比肩在月=感情竞争等

## 明确说不确定的

- 具体职业、长相细节、籍贯、何时遇到——八字推不出来

## 示例输出结构

```
【正缘核心星】
- 正财/正官 = X，藏于X柱/X柱
- 夫妻宫 = X支，藏干 = [...]

【从正财/正官推】
- 五行特征、出现时机、外显程度、属相

【从夫妻宫推】
- 五行、生肖、外貌倾向、性格、对日主的影响

【十神视角】
- 劫财/比肩/偏财等对感情的影响

【结论】
- 仅从干支可推出的特征（编号列表）
```
