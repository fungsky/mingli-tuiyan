# 合婚推演方法（干支互动视角）

结合四柱干支的合/冲/互动判断两人关系的**结构特征**。
「无法从八字确定」的就说无法确定。命理是概率性倾向参考，不作决策依据。

## 核心逻辑

1. **天干五合**：甲己合土 / 乙庚合金 / 丙辛合水 / 丁壬合木 / 戊癸合火
   - 双方年柱天干相合 = 缘起层面的牵引（"认识是注定感"的来源之一）
   - 双方时柱天干相合 = 归宿层面的指向（时柱管晚年）
2. **地支六合**：子丑合 / 寅亥合 / 卯戌合 / 辰酉合 / 巳申合 / 午未合
   - 时柱天地双合（天干合 + 地支六合同时成立）是较深的"归宿合"
3. **日主同气**：双方日干五行相同 = 理解成本低、共情强；但情绪模式也可能相似（都闷着不说）
4. **日支互动**（双方夫妻宫）：
   - 一方日支被另一方地支合 = 对方能量主动贴近婚姻宫
   - 一方日支被冲 = 婚姻宫本身动荡，怕外部结构冲击
5. **五行喜忌互补**（最重要的"互旺"判断）：
   - 先判各自喜用（见 tuiyan.py 强弱视角）
   - A 喜金水、B 全局金水旺 → B 的存在"补"A → A 与 B 相处状态回升
   - 互补 = 各自盘里最需要的东西，对方盘里天生就有

## 分析维度清单

| 部位 | 看什么 | 含义 |
|------|--------|------|
| 年柱互动 | 天干合 / 地支暗合 | 缘起牵引、长辈层面认可度 |
| 日主关系 | 同气 / 相生 / 相克 | 沟通成本、共情模式 |
| 夫妻宫（日支） | 双方地支的合冲刑害 | 感情结构稳定性 |
| 时柱互动 | 天地双合？ | 归宿/晚年指向 |
| 五行喜忌 | 互补 or 同缺 | 长期相处的滋养度 |

## 明确说不确定的

- 具体在一起的时间点、会不会结婚、白头偕老——八字推不出来
- 婚姻是两个人的选择与经营，命理只描述结构倾向

## 输出结构

```
【天干合】
- 年柱/月柱/时柱 各有哪些合
【地支互动】
- 六合/三合/冲/刑 的位置与指向
【夫妻宫视角】
- 双方日支的互动与各自婚姻宫强弱
【五行互旺】
- A 喜用 → B 提供了什么
- B 喜用 → A 提供了什么
【结论】
- 合的层次 + 张力点（可证伪描述，不打包票）
```

## 注意事项

- 第三方报告的合婚结论不可信，先逐项核对四柱/大运/十神（见 third-party-verification.md）
- 合婚中涉及具体人时保持第三人称客观描述，不代入
